## Concurrent Multi-Agent Isolation Protocol (Mandatory Step 0)

Multiple coding agents may be launched from `/Users/dominicbarker/LikeHome-bench` **simultaneously**. Therefore, `/Users/dominicbarker/LikeHome-bench` is a **read-only template directory**—do **NOT** modify files, install packages, or run builds directly inside `/Users/dominicbarker/LikeHome-bench`.

Before doing any implementation work, you **must** create and move into your own isolated run workspace:

1. **Generate a unique `<run-id>`**:
   - Format: `<agent-or-model>-<4-char-hex>` (for example: `claude-a4f2`, `codex-8b1c`, `gemini-3d9e`, or `agent-$(openssl rand -hex 2)`).
2. **Copy this template into your own isolated workspace**:
   ```bash
   mkdir -p /Users/dominicbarker/LikeHome-runs
   cp -R /Users/dominicbarker/LikeHome-bench "/Users/dominicbarker/LikeHome-runs/likehome-${RUN_ID}"
   cd "/Users/dominicbarker/LikeHome-runs/likehome-${RUN_ID}"
   ```
   All file edits, `npm ci`, builds, tests, and git commits must happen strictly inside `/Users/dominicbarker/LikeHome-runs/likehome-${RUN_ID}` (and `/tmp/likehome-${RUN_ID}/` for temporary scratch files).
3. **Strict Neighbor Isolation**:
   - Do **NOT** read, inspect, or copy code from `/Users/dominicbarker/LikeHome`, `/Users/dominicbarker/Desktop`, or any other sibling directory inside `/Users/dominicbarker/LikeHome-runs/`.
   - Do **NOT** inspect or clone existing `LikeHome*` repositories on GitHub or existing `LikeHome*` projects on Railway.
4. **Collision-Free Ports, Containers, GitHub Repo & Railway Project**:
   - **Local PostgreSQL Port & Container**: Another agent may already be using port `5434` or `5435`. Probe for a free localhost TCP port in the `5435–5499` range before starting Docker Compose, and name your container/volume uniquely (`likehome-${RUN_ID}-postgres`).
   - **Local Dev / E2E Server Port**: Probe for a free port in the `3100–3199` range for your Playwright `webServer` and local preview verification so concurrent E2E runs never collide on port `3000`.
   - **GitHub Repository**: Create a brand-new repository named **`DomBarker99/LikeHome-${RUN_ID}`**.
   - **Railway Project**: Create a brand-new Railway project named **`LikeHome-${RUN_ID}`** with its own PostgreSQL service and public domain.
